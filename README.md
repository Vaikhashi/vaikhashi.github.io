# vaikhashi.github.io

My portfolio site: https://vaikhashi.github.io

The work section is a `git log --graph` of my career, and every project has a small demo you can play on the page. Press <kbd>/</kbd> for a command palette.

It's one `index.html` with no framework and no build step. To run it locally:

```bash
git clone https://github.com/Vaikhashi/vaikhashi.github.io
cd vaikhashi.github.io
python -m http.server 8000
```

Then open http://localhost:8000.
